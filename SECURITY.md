# Security Policy

## Supported Versions

Only the latest published version receives fixes.

## Reporting a Vulnerability

Report it through GitHub's private vulnerability reporting:
**[Open a private vulnerability report](https://github.com/anilcancakir/magic_social_auth/security/advisories/new)**

The report stays confidential until a fix is ready. Include the affected version, the platform, and the steps to reproduce.

## Scope

This policy covers the `magic_social_auth` package: the `SocialAuth` facade and manager, the Google, Apple and browser-flow drivers with their PKCE and nonce handling, `SocialAuthButtons` and the `social:install` and `social:doctor` commands. Issues in `google_sign_in`, `sign_in_with_apple`, `flutter_web_auth_2`, `dowel` and the Flutter SDK belong to their maintainers.
